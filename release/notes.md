## [1.7.0] - 2026-11-04

### Added
- **Startup > choose what to restore**: RESTORE (n) opens a list of the removed entries with the date, source and command of each. Put back one entry with RESTORE, all of them with RESTORE ALL, or delete a saved copy for good with FORGET.
- **Boost > process details**: every process now shows its program icon, description, publisher, threads and PID in the list, with a search box (name, description, publisher, path or PID) and a summary of processes / threads / handles. Selecting a process opens a details panel: live CPU, memory, threads and handles, the file and version, private and peak memory, when it started and how long it has run, CPU time, priority, architecture, parent process, user, session, command line, window state and - for service hosts - the Windows services it runs. SHOW IN EXPLORER and COPY PATH buttons work on its file.
